# Customer App

React + Vite customer-facing ordering application for QRserv. Customers use this app to open a restaurant menu from a QR code, add items to cart, place orders, pay online or cash where allowed, view order status, and download bill PDFs.

## Tech Stack

- React 19
- Vite 7
- Tailwind CSS 4
- Axios
- React Router
- jsPDF
- pdfjs-dist

## Requirements

- Node.js 20+
- npm 10+
- Running backend API

## Environment Variables

Create `customer-app/.env`:

```env
VITE_API_URL=http://localhost:7000/api
```

## Install

```bash
npm install
```

## Run Locally

```bash
npm run dev
```

Default local URL:

```text
http://localhost:5174
```

If `VITE_API_URL` is not set, the app falls back to `/api` and Vite proxies API requests to `https://srv1563916.hstgr.cloud` in development.

## Build

```bash
npm run build
```

Build output:

```text
dist/
```

Preview production build locally:

```bash
npm run preview
```

## Deployment

This is a static SPA. Deploy the `dist` folder to Netlify, Vercel, Hostinger static hosting, or Nginx/Apache.

Recommended production env:

```env
VITE_API_URL=https://your-backend-domain/api
```

### Netlify

This project already includes `netlify.toml` and `public/_redirects`.

Build settings:

```text
Base directory: customer-app
Build command: npm run build
Publish directory: dist
```

### Nginx

Serve `dist` and rewrite unknown routes to `index.html`.

## QR Flow

This app depends on table or restaurant URLs generated by the admin panel. Make sure the production customer app domain matches the URL configured in the admin panel via `VITE_CUSTOMER_APP_URL`.
